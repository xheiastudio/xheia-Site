# Xheia

Marketing site for Xheia — a full-stack data consultancy. Built with [Astro](https://astro.build), static output, deployed on Netlify.

See `BRANDFINAL.md` for brand source of truth and `SPEC.md` for the implementation spec. `CLAUDE.md` has repo-specific working guidance.

## Commands

| Command | Action |
|---|---|
| `npm run dev` | Local dev server |
| `npm run build` | Production build to `dist/` (also what Netlify runs) |
| `npm run preview` | Serve the built `dist/` locally |
| `npm run check` | Astro + TypeScript type-checking |
| `npm run lint` | Alias for `npm run check` |
